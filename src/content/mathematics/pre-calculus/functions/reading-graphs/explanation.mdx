A graph stores every value of a function at once. Four questions come up again and again, and each
one has a fixed way of reading the answer off the picture. The function in this lesson is

$$
f(x) = \frac{x^3 - 12x}{8} + 1, \qquad -4 \leq x \leq 4,
$$

but every answer can be read from the graph without it.

## Values: $f(a)$

The point of the graph above $a$ is $(a, f(a))$. Go up from $a$ to the curve, then across to the
$y$-axis. A point $(a, b)$ lies on the graph exactly when $f(a) = b$.

## Equations: $f(x) = c$

Solving $f(x) = c$ asks for the inputs with output $c$. Draw the horizontal line $y = c$; each crossing
with the graph is a solution, read down on the $x$-axis. The number of crossings is the number of
solutions: here $f(x) = 1$ has three, $f(x) = 3$ has two, and $f(x) = 4$ has none.

## Increasing and decreasing

$f$ is increasing on an interval if larger inputs give larger outputs there:

$$
x_1 < x_2 \implies f(x_1) < f(x_2).
$$

Decreasing reverses the second inequality. The intervals are written with $x$ values. This graph
increases on $[-4, -2]$, <C c="red">decreases</C> on $[-2, 2]$ and increases again on $[2, 4]$.

## Maximum, minimum and range

The largest output is the maximum, the smallest the minimum. For a graph without gaps, the range runs
from the minimum to the maximum:

$$
\min f = -1, \qquad \max f = 3, \qquad \text{range}(f) = [-1, 3].
$$

The ends of the domain matter. The value $f(4) = 3$ at the right end ties the peak at $x = -2$, and
$f(-4) = -1$ ties the valley at $x = 2$. Practice these readings with formulas in the next item.
