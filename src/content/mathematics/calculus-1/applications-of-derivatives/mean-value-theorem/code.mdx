The mean value theorem promises a $c$; SymPy finds it. Then the speed check from samples, the way a
camera system would do it.

## Rolle's theorem

$B$ is the other point at the height of $A$. The flat tangents between them are the solutions
of $f'(c) = 0$ inside $(a, b)$:

```python title="rolle.py" step=rolle colors="f=blue" check
import numpy as np
import sympy as sp

x = sp.symbols("x")
f = sp.Rational(1, 5) * x**3 - sp.Rational(6, 5) * x**2 \
    + sp.Rational(9, 5) * x + 1
a = sp.Rational(3, 10)

others = sp.solve(sp.Eq(f, f.subs(x, a)), x)
b = max(others)
print([round(float(r), 4) for r in others])
print([c for c in sp.solve(sp.diff(f, x), x) if a < c < b])
```

```output
[0.3, 1.9376, 3.7624]
[1, 3]
```

## Tilt the chord

With $b = 4.6$, solve $f'(c)$ = the chord's slope:

```python title="mvt.py" step=mvt colors="slope=orange cs=teal" hover="slope=chord cs=tangent" check
def mvt_points(
    g: sp.Expr, a: sp.Expr, b: sp.Expr
) -> tuple[sp.Expr, list[float]]:
    slope = (g.subs(x, b) - g.subs(x, a)) / (b - a)
    roots = sp.solve(sp.Eq(sp.diff(g, x), slope), x)
    return slope, [float(c) for c in roots if a < c < b]

b = sp.Rational(23, 5)
slope, cs = mvt_points(f, a, b)
print(float(slope), [round(c, 4) for c in cs])
```

```output
0.446 [0.6796, 3.3204]
```

## Back to Rolle

The gap $h$ is $0$ at both ends, and $h'$ is $0$ at the same points:

```python title="proof.py" step=proof colors="h=purple" hover="h=gap" check
h = f - (f.subs(x, a) + slope * (x - a))
print(h.subs(x, a), h.subs(x, b))
print([round(float(h.diff(x).subs(x, c)), 12) for c in cs])
```

```output
0 0
[0.0, 0.0]
```

## A corner breaks it

$|x - 2| + 1$ on $[0.5, 4]$: the chord's slope is $\frac{1}{7}$, and the derivative takes only
the values $-1$ and $1$:

```python title="fails.py" step=fails check
g = sp.Abs(x - 2) + 1
lo, hi = sp.Rational(1, 2), 4
print((g.subs(x, hi) - g.subs(x, lo)) / (hi - lo))
print(sorted({sp.sign(t - 2) for t in np.linspace(0.5, 4, 9)}))
```

```output
1/7
[-1, 1]
```

## An average speed check

The trip as samples, one per second. The average over the section, and the instants when the
speedometer read it, found where `speed - average` changes sign:

```python title="speed.py" step=speed colors="average=orange" hover="average=chord" check
hours = np.linspace(0, 1.5, 5401)
km = (320 / 3 * hours + 12 * np.sin(4 * np.pi * hours / 3)
      + 4 * np.sin(8 * np.pi * hours / 3))
average = (km[-1] - km[0]) / (hours[-1] - hours[0])
speed = np.gradient(km, hours)

crossing = np.nonzero(np.diff(np.sign(speed - average)))[0]
print(round(average, 1))
print((hours[crossing] * 60).round(1), speed[crossing].round(1))
```

```output
106.7
[16.2 73.8] [106.7 106.6]
```

## Same slope, a constant apart

Adding a constant does not change the derivative, and by the theorem that is the only way two
functions on an interval can share one:

```python title="same_slope.py" step=same-slope check
C = sp.symbols("C")
print(sp.diff(f + C, x) - sp.diff(f, x))
print(sp.integrate(sp.diff(f, x), x))
```

```output
0
x**3/5 - 6*x**2/5 + 9*x/5
```

`integrate` returns one of them; the others are this plus $C$.
