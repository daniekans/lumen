A proof's rule is a function: it takes `eps` and returns `delta`. The code below writes each
rule of this lesson as a Python function and tests it by sampling inputs in the window. That is
a test, not a proof. It checks finitely many $x$ and finitely many tolerances, so it can catch a
wrong rule but never show that a rule works for every $x$ and every $\varepsilon$. Only the
written argument does that.

## A rule for a line

For $2x + 1$ near $1$ the rule is $\delta = \frac{\varepsilon}{2}$. `passes` samples the window on
both sides, never $x = a$ itself, and the loop tries the rule on tolerances from large to tiny:

```python title="linear.py" step="definition linear" focus="definition=3-7 linear=9-14" colors="eps=teal delta=yellow" check
import numpy as np

def passes(h, a: float, L: float, eps: float, delta: float) -> bool:
    """Every sampled x with 0 < |x - a| < delta lands in the band."""
    t = np.linspace(1e-9, delta, 2000, endpoint=False)
    x = np.concatenate([a - t, a + t])
    return bool(np.all(np.abs(h(x) - L) < eps))

def delta_line(eps: float) -> float:
    return eps / 2  # from |(2x + 1) - 3| = 2|x - 1|

tolerances = [6.0, 1.0, 0.3, 1e-3, 1e-6]
print([passes(lambda x: 2 * x + 1, 1, 3, e, delta_line(e))
       for e in tolerances])
```

```output
[True, True, True, True, True]
```

## Bounding the extra factor

For $x^2$ near $1$ the rule needs the minimum. Without the `1`, a large tolerance gives a window
that reaches past $x = 2$, where the bound $|x + 1| < 3$ no longer holds, and the test catches it
at $\varepsilon = 6$:

```python title="square.py" step="quadratic restriction" focus="quadratic=1-2 restriction=4-11" colors="eps=teal delta=yellow" check
def delta_square(eps: float) -> float:
    return min(1.0, eps / 3)  # keep |x - 1| < 1, then |x + 1| < 3

def delta_third(eps: float) -> float:
    return eps / 3  # the bound on |x + 1| is not guaranteed

def square(x):
    return x**2

for e in (0.6, 2.0, 6.0):
    print(e, passes(square, 1, 1, e, delta_square(e)),
          passes(square, 1, 1, e, delta_third(e)))
```

```output
0.6 True True
2.0 True True
6.0 True False
```

## Proving a limit law

Each function gets half the tolerance and its own window; the sum uses the smaller one. Here
$|f(x) - 1| = \frac{|x - 1|}{2}$ and $|g(x) - 2| \le 1.2\,|x - 1|$ give the two rules:

```python title="sum_law.py" step=sum-law colors="eps=teal delta=yellow f=blue g=blue" check
def f(x):
    return (x + 1) / 2

def g(x):
    return 2 + 1.2 * np.sin(x - 1)

def delta_sum(eps: float) -> float:
    delta_f = eps  # |f - 1| < eps / 2
    delta_g = (eps / 2) / 1.2  # |g - 2| < eps / 2
    return min(delta_f, delta_g)

print([passes(lambda x: f(x) + g(x), 1, 3, e, delta_sum(e))
       for e in (1.6, 0.6, 1e-4)])
```

```output
[True, True, True]
```

## Proving that a limit does not exist

For the step function, every window holds $x_1 = -\frac{\delta}{2}$ and $x_2 = \frac{\delta}{2}$.
Whatever `L` is claimed, one of the two is at least $1$ away from it. The loop tries a grid of
claims and windows; the inequality in the explanation covers all the others:

```python title="no_limit.py" step=no-limit colors="L=teal delta=yellow" check
def step(x):
    return np.where(x < 0, -1.0, 1.0)

worst = min(
    max(abs(step(-d / 2) - L), abs(step(d / 2) - L))
    for L in np.linspace(-3, 3, 601)
    for d in (1.0, 0.1, 1e-6)
)
print(worst)  # never below eps = 1
```

```output
1.0
```
