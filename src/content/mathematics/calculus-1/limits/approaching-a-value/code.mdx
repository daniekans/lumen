A limit can be estimated with numbers and computed exactly with algebra. The blocks below do
both for the stage's $f(x) = \frac{x^3 - 1}{x - 1}$: NumPy for the table of values near $1$,
SymPy for the exact limit. Floats also show where "as close as you like" stops in a computer.

## Closing in from both sides

`d` is the distance from $1$, shrinking by a factor of ten. The other two columns are
$f(1 - d)$ and $f(1 + d)$, the left and right points of the stage:

```python title="approach.py" step=approach colors="f=blue d=yellow" check
import numpy as np
import sympy as sp

def f(x: float) -> float:
    return (x**3 - 1) / (x - 1)

for d in [1.0, 0.1, 0.01, 0.001]:
    print(d, round(f(1 - d), 6), round(f(1 + d), 6))
```

```output
1.0 1.0 7.0
0.1 2.71 3.31
0.01 2.9701 3.0301
0.001 2.997001 3.003001
```

A table suggests the limit; SymPy computes it from the formula:

```python title="limit.py" step=approach colors="f=blue" check
x = sp.symbols("x")
f_expr = (x**3 - 1) / (x - 1)
print(sp.limit(f_expr, x, 1))
print(sp.limit(f_expr, x, 1, "-"), sp.limit(f_expr, x, 1, "+"))
```

```output
3
3 3
```

## Zooming in, and where floats stop

The last column is the float's error against the exact $3 + 3d + d^2$. It grows as `d`
shrinks, because $x^3 - 1$ cancels the leading digits the two numbers share:

```python title="zoom.py" step=zoom colors="f=blue d=yellow" check
for d in [1e-2, 1e-4, 1e-6, 1e-8]:
    exact = 3 + 3 * d + d**2
    print(d, f(1 + d), f"{f(1 + d) - exact:.0e}")
print(1 + 1e-16 == 1)  # x is 1 again
```

```output
0.01 3.0301000000000107 1e-14
0.0001 3.0003000099990658 -9e-13
1e-06 3.0000030000446576 4e-11
1e-08 3.0000000222044605 -8e-09
True
```

Dividing by the tiny $x - 1$ magnifies what is left. At $d = 10^{-16}$ there is no float between
$1$ and $1 + d$, and `f` would divide by zero. The limit is a statement about real numbers;
floats only approximate it.

## The value at 1 does not matter

Substituting $x = 1$ into the formula gives $\frac{0}{0}$, which SymPy reports as `nan`. The limit
never substitutes: it is the same for any value assigned at $1$, because `cancel` shows what the
function is for $x \neq 1$:

```python title="value.py" step=value-differs colors="f_expr=blue" check
print(f_expr.subs(x, 1))
print(sp.cancel(f_expr))

def f_filled(x: float, at_one: float) -> float:
    return at_one if x == 1 else (x**3 - 1) / (x - 1)

for at_one in [5.0, 3.0]:
    print(f_filled(1, at_one), round(f_filled(1.001, at_one), 6))
```

```output
nan
x**2 + x + 1
5.0 3.003001
3.0 3.003001
```

## Increments

With the hole filled, $g(x) = x^2 + x + 1$. `dy / dx` is the slope from $(1, 3)$ to $P$, and
SymPy simplifies it to $3 + \Delta x$ before taking the limit:

```python title="increments.py" step=increments colors="g=blue dx=yellow dy=teal" check
def g(x: float) -> float:
    return x**2 + x + 1

for dx in [1.2, 0.3, 0.01]:
    dy = g(1 + dx) - g(1)
    print(dx, round(dy, 4), round(dy / dx, 4))

Dx = sp.symbols("Delta_x")
ratio = ((1 + Dx)**2 + (1 + Dx) + 1 - 3) / Dx
print(sp.simplify(ratio), sp.limit(ratio, Dx, 0))
```

```output
1.2 5.04 4.2
0.3 0.99 3.3
0.01 0.0301 3.01
Delta_x + 3 3
```
