The blocks below compute the stage's secant slopes with NumPy and the exact derivative with SymPy.
They also show where a computer meets the limit: shrinking $h$ helps only up to a point, because
floating-point numbers carry about 16 significant digits. Hover a name to light its shape.

## The secant slope

`f` is the stage's curve, `P` and `Q` its two points. The slope is the difference quotient,
rise over run:

```python title="secant.py" step=secant colors="f=blue Q=yellow slope=yellow" hover="f=f Q=secant slope=secant P=P" check
import numpy as np

def f(x: float) -> float:
    return 0.1 * x**3 - 0.8 * x**2 + 1.6 * x + 1

x0, h = 1.2, 2.2
P = (x0, f(x0))
Q = (x0 + h, f(x0 + h))
slope = (Q[1] - P[1]) / (Q[0] - P[0])  # dy / h
print(np.round(P, 4), np.round(Q, 4))
print(round(slope, 4))
```

```output
[1.2    1.9408] [3.4    1.1224]
-0.372
```

## Shrink the gap

The same quotient for smaller and smaller `h`. Rise and run both go to zero; their ratio settles:

```python title="shrink.py" step=shrink colors="slope=yellow" hover="slope=secant" check
def slope(x0: float, h: float) -> float:
    return (f(x0 + h) - f(x0)) / h

for h in [2.2, 1.0, 0.6, 0.1, 0.01, 0.001]:
    print(f"{h:<6} {f(x0 + h) - f(x0):+.6f} {slope(x0, h):+.6f}")
```

```output

1.0    -0.228000 -0.228000
0.6    -0.069600 -0.116000
0.1    +0.006900 +0.069000
0.01   +0.001076 +0.107610
0.001  +0.000112 +0.111560
```

## The limit, exactly and in floats

SymPy takes the limit of the quotient symbolically and gets $f'(1.2)$ exactly. Floats cannot let `h`
reach zero, so the loop tries powers of ten. The error falls until about `1e-8`, then grows: the
two heights agree in almost all their digits, and their difference keeps only the rounding noise. `h = 1e-12` is worse than `h = 1e-6`:

```python title="limit.py" step=limit colors="fx=blue F=blue exact=teal slope=yellow" hover="fx=f F=f exact=tangent slope=secant" check
import sympy as sp

x, t = sp.symbols("x h")
fx = sp.nsimplify("0.1*x**3 - 0.8*x**2 + 1.6*x + 1")
F = sp.Lambda(x, fx)
x_0 = sp.Rational(6, 5)  # exact 1.2
exact = sp.limit((F(x_0 + t) - F(x_0)) / t, t, 0)
print(exact, float(exact))

for k in [2, 4, 6, 8, 10, 12, 14]:
    err = abs(slope(x0, 10.0**-k) - float(exact))
    print(f"1e-{k:<3} {err:.1e}")
```

```output

1e-2   4.4e-03
1e-4   4.4e-05
1e-6   4.4e-07
1e-8   9.3e-09
1e-10  7.0e-07
1e-12  3.5e-04
1e-14  9.8e-04
```

## Locally straight

The gap between the curve and its tangent, divided by the distance `d` from $P$. It goes to zero,
so under magnification the gap disappears faster than the picture grows:

```python title="zoom.py" step=zoom colors="tangent=teal f=blue" hover="tangent=tangent f=f" check
m = float(exact)

def tangent(x: float) -> float:
    return f(x0) + m * (x - x0)

for d in [1.0, 0.1, 0.01, 0.001]:
    gap = abs(f(x0 + d) - tangent(x0 + d))
    print(f"{d:<6} {gap:.2e} {gap / d:.2e}")
```

```output
1.0    3.40e-01 3.40e-01
0.1    4.30e-03 4.30e-02
0.01   4.39e-05 4.39e-03
0.001  4.40e-07 4.40e-04
```

## The derivative function

`sp.diff` does the limit at every $x$ at once and returns $f'$ as an expression. `lambdify`
turns it into a NumPy function, here evaluated at $x_0 = 1.2$ and at the check's $x = 2$:

```python title="derivative.py" step=notation colors="fx=blue dfdx=teal" hover="fx=f dfdx=fprime" check
dfdx = sp.diff(fx, x)
print(dfdx)
flat = sp.solve(dfdx, x)  # where the tangent is flat
print(flat, [dfdx.subs(x, r) for r in flat])

df = sp.lambdify(x, dfdx, "numpy")
print(df(np.array([1.2, 2.0])))
```

```output
3*x**2/10 - 8*x/5 + 8/5
[4/3, 4] [0, 0]
[ 0.112 -0.4  ]
```
