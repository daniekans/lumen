Each fact of the item is one comparison: two numbers that the product rule says are equal.

## Products, flips and powers

```python title="product.py" step="twice flips powers" focus="twice=1-6 flips=8-10 powers=12-13" colors="A=green B=red" check
import numpy as np

det = lambda M: round(float(np.linalg.det(M)), 9)
A = np.array([[2, 0.5], [0, 1]])
B = np.array([[1, 0], [0.5, 1.5]])
print(det(B @ A), det(B) * det(A))

R_diag = np.array([[0, 1], [1, 0]])  # across y = x
R_x = np.array([[1, 0], [0, -1]])  # across the x-axis
print(det(R_diag), det(R_x), R_x @ R_diag)

A_pow = np.array([[1.25, 0.25], [0, 1.2]])
print(det(np.linalg.matrix_power(A_pow, 4)), det(A_pow) ** 4)
```

```output
3.0 3.0
-1.0 -1.0 [[ 0  1]
 [-1  0]]
5.0625 5.0625
```

The two reflections together are $\begin{bmatrix} 0 & 1 \\ -1 & 0 \end{bmatrix}$, the rotation by
$90^\circ$ clockwise.

## A preview of eigenvalues

SymPy writes $\det(A - \lambda I)$ as a polynomial in $\lambda$ and finds where it is $0$:

```python title="eigen.py" step=eigen check
import sympy as sp

lam = sp.symbols("lambda")
A_s = sp.Matrix([[2, 1], [1, 2]])
p = (A_s - lam * sp.eye(2)).det()
print(sp.factor(p), sp.solve(p, lam))
print(np.linalg.eigvalsh(np.array([[2.0, 1], [1, 2]])))
```

```output
(lambda - 3)*(lambda - 1) [1, 3]
[1. 3.]
```

## Log-determinants add

Forty layers, each a rotation scaled by $2$ in $50$ dimensions, so $|\det| = 2^{50}$ for each. The
product of the determinants overflows a float; the sum of their logarithms, $40 \cdot 50 \ln 2$, does
not, and it matches the log-determinant of the whole chain. `slogdet` returns the sign and $\log|\det|$:

```python title="logdet.py" check
rng = np.random.default_rng(0)
Q = lambda: np.linalg.qr(rng.normal(size=(50, 50)))[0]  # a rotation
layers = [2 * Q() for _ in range(40)]  # det = ±2^50 each
logs = [np.linalg.slogdet(W)[1] for W in layers]
print(np.prod([np.linalg.det(W) for W in layers]))
print(round(sum(logs), 6))
total = np.linalg.multi_dot(layers[::-1])
print(round(np.linalg.slogdet(total)[1], 6))
```

```output
inf
1386.294361
1386.294361
```
