NumPy computes the determinant with `np.linalg.det`. Here it is checked against the picture: the
area of the parallelogram the unit square lands on, measured from its corners.

## The unit square

The corners of the unit square, as columns, go through `A` in one product. `area` is the
shoelace formula, the signed area of a polygon from its corners:

```python title="area.py" step=square colors="A=yellow" check
import numpy as np

def area(P: np.ndarray) -> float:  # corners as columns, in order
    x, y = P
    return 0.5 * np.sum(x * np.roll(y, -1) - np.roll(x, -1) * y)

A = np.array([[2.0, 1.0], [1.0, 2.0]])
square = np.array([[0, 1, 1, 0], [0, 0, 1, 1]])
print(A @ square)  # the parallelogram's corners
print(area(A @ square), np.linalg.det(A))
```

```output
[[0. 2. 3. 1.]
 [0. 1. 3. 2.]]
3.0 2.9999999999999996
```

`np.linalg.det` works in floating point (by elimination, as the lesson on computing determinants
explains), so it can be off in the last digit.

## Every grid square

A grid square at `q` lands on the same parallelogram shifted by `A @ q`, so its area is the same:

```python title="cells.py" step=grid-squares check
for q in [(0, 0), (-1, 0), (1, -1), (-1, -1)]:
    cell = square + np.array(q).reshape(2, 1)  # shift the square
    print(q, area(A @ cell))
```

```output
(0, 0) 3.0
(-1, 0) 3.0
(1, -1) 3.0
(-1, -1) 3.0
```

## Any region

The squares of side `h` inside the unit disk, counted by their corners. Their images have exactly
three times their total area, and the total approaches $\pi$:

```python title="disk.py" step=any-region check
def squares_in_disk(h: float) -> int:
    k = np.arange(-int(1 / h), int(1 / h))
    x, y = np.meshgrid(k * h, k * h)
    far = np.maximum(np.abs(x), np.abs(x + h))  # farther side
    up = np.maximum(np.abs(y), np.abs(y + h))
    return int(np.sum(far**2 + up**2 <= 1))

d = np.linalg.det(A)
for h in [0.5, 0.25, 0.125, 0.0625, 0.001]:
    inside = squares_in_disk(h) * h * h
    print(h, round(inside, 4), round(d * inside, 4))
print(np.pi, 3 * np.pi)
```

```output
0.5 1.0 3.0
0.25 2.0 6.0
0.125 2.5625 7.6875
0.0625 2.8594 8.5781
0.001 3.1375 9.4126
3.141592653589793 9.42477796076938
```

## The sign

Moving the second column across the line of the first flips the turn between them, and the
determinant changes sign:

```python title="flip.py" step=sign check
F = np.array([[2.0, 2.5], [1.0, -0.25]])  # second column moved
print(area(F @ square), round(np.linalg.det(F), 6))
```

```output
-3.0 -3.0
```

The shoelace formula gives $-3$ too: the image's corners now go clockwise.

## Collapse

Columns on one line give $0$. In floating point, a collapse can come out as a tiny number
instead, so code asks for the <Term id="rank">rank</Term>, the dimension of the image:

```python title="collapse.py" step=collapse check
L = np.array([[2.0, 1.0], [1.0, 0.5]])  # column 2 = column 1 / 2
print(np.linalg.det(L), np.linalg.matrix_rank(L))
M = np.array([[0.1, 0.3], [0.7, 2.1]])  # column 2 = 3 column 1
print(np.linalg.det(M), np.linalg.matrix_rank(M))
```

```output
0.0 1
3.885780586188033e-17 1
```

The second determinant should be $0$; rounding leaves about $10^{-17}$. The rank, $1$, says the
plane lands on a line.

## Zooming into a curved map

SymPy finds the local matrix $J$ of the curved map exactly, as a matrix of derivatives, and its
determinant at each point of the step:

```python title="jacobian.py" step=curved check
import sympy as sp

x, y = sp.symbols("x y")
f = sp.Matrix([x + sp.Rational(3, 5) * sp.sin(y),
               y + sp.Rational(3, 5) * sp.sin(x)])
J = f.jacobian([x, y])
print(J)
print(sp.simplify(J.det()))
for p in [(0, 0), (1.5, 0.5), (3, 0)]:
    print(p, round(float(J.det().subs({x: p[0], y: p[1]})), 4))
```

```output
Matrix([[1, 3*cos(y)/5], [3*cos(x)/5, 1]])
-9*cos(x)*cos(y)/25 + 1
(0, 0) 0.64
(1.5, 0.5) 0.9777
(3, 0) 1.3564
```
